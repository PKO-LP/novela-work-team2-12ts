# Новелла «Последняя электричка»

## Задача проекта
Создать интерактивную консольную текстовую новеллу на чистом Python для курса ДУП.03 с ветвящимся сюжетом, пятью рабочими функциями, системой учета ресурсов и двумя концовками.

## Для кого продукт
Игра предназначена для студентов групп 11ТЭС и 12ТЭС, преподавателей и любителей текстовых квестов. Игрокам новелла интересна жизненным ночным сюжетом и выбором тактики, а начинающим программистам подойдет как понятный пример использования циклов, условий и функций `def`.

## О чём игра
Вы уснули в электричке после тяжелого дня и очнулись глубокой ночью на пустой тупиковой станции «Лосиный Лог». Поездов до утра больше не будет, на улице мороз, в кармане всего **200 рублей**, а на телефоне осталось **7% заряда**.

Чтобы успеть на последний ночной автобус с соседней станции, нужно поговорить с дежурным Пахомием, решить, доверять ли бродяге Степанычу, и правильно потратить ресурсы.

## Как запустить
1. скачать проект `git clone https://github.com/PKO-LP/novela-work-team2-12ts.git`
2. Откройте папку финальной версии `v1.0` (или найдите файл `main.py` в корне репозитория).
3. Убедитесь, что на компьютере установлен Python 3.8 или выше.
4. Откройте терминал в папке с файлом и выполните команду:
   `python main.py`

## Как играть
1. В главном меню введите `1` и нажмите Enter для начала игры (`0` закрывает программу).
2. Следите за строкой статуса с деньгами и зарядом батареи, читайте текст сцен и вводите цифру нужного действия (`1`, `2` или `3`). Каждый выбор влияет на остаток денег, заряд телефона и финальную концовку.

## Особенности финальной версии (v1.0)
* **5 рабочих функций (`def`):** главное меню, отображение статуса ресурсов, сцена на перроне, сцена у автомата и расчет финала.
* **Управление ресурсами:** каждый выбор тратит деньги или проценты заряда телефона, при повторном запуске игры ресурсы корректно сбрасываются.
* **Нелинейность:** несколько путей к цели и 2 основные концовки (успеть домой или застрять на станции до утра).
* **Простой запуск:** написана на чистом Python без сторонних библиотек, работает в любой консоли.
